# APISK 快速接入：5 分钟跑通百度搜索接口

本教程以 **`GET https://www.baidu.com/s?wd=天气`** 为示例接口，从脚手架初始化到用例执行，完整走一遍。

> 要求：Python 3.9+、已安装 pip。
> 示例环境：Windows PowerShell。

---

## Step 1：安装框架（30 秒）

```powershell
pip install apisk
```

apisk 会自动拉上 pytest、pytest-html、requests 三个依赖。装完之后 pytest 自动认识 apisk（entry_point 注册），`python -m apisk.scaffold` 也直接可用。

```powershell
# 验证
python -c "import apisk; print(apisk.__version__)"
# 预期：3.0.0
```

---

## Step 2：脚手架初始化（30 秒）

### 2.1 一条命令生成骨架

```powershell
python -m apisk.scaffold --name baidu --out test_baidu --force
# python -m apisk.scaffold --name baidu --base-url https://www.baidu.com --probe "https://www.baidu.com/s?wd=%E5%A4%A9%E6%B0%94" --out test_baidu --force
```

| 参数 | 说明 | 本示例值 |
|------|------|----------|
| `--name` | 业务领域名（英文、小写、无空格） | `baidu` |
| `--base-url` | 被测服务根地址 | `https://www.baidu.com` |
| `--probe` | 门禁探测端点（完整 URL 或路径均可） | `https://www.baidu.com/s?wd=天气` |
| `--out` | 输出目录 | `test_baidu` |
| `--force` | 目录存在时覆盖 | — |

### 2.2 确认生成结构


## Step 3：修改领域包（2 分钟）

脚手架默认生成的是 ping 端点示例。现在改成我们的搜索端点 `GET /s?wd=天气`。

### 3.1 打开 `domain/baidu_domain.py`

### 3.2 改写为：

```python
from dataclasses import dataclass

from apisk.api import BaseApi
from apisk.core import HttpClient
from apisk.domain import Domain, ServiceSpec


@dataclass(frozen=True)
class BaiduConfig:
    BASE_URL = "https://www.baidu.com"
    SEARCH_PATH = "/s"
    TIMEOUT = 15


config = BaiduConfig()


class BaiduApi(BaseApi):
    def search(self, keyword, **kwargs):
        """GET https://www.baidu.com/s?wd={keyword}"""
        return self._get(
            f"{config.BASE_URL}{config.SEARCH_PATH}",
            params={"wd": keyword},
            **kwargs,
        )


class BaiduService:
    def __init__(self):
        self.api = BaiduApi(HttpClient(
            base_url=config.BASE_URL,
            timeout=config.TIMEOUT,
        ))

    def search(self, keyword="天气"):
        return self.api.search(keyword)


DOMAIN = Domain(
    name="baidu",
    apis={"search": BaiduApi},
    services=[ServiceSpec("baidu", BaiduService)],
    probe=f"{config.BASE_URL}{config.SEARCH_PATH}",
    config=config,
)

__all__ = ["DOMAIN", "BaiduApi", "BaiduConfig", "BaiduService", "config"]
```

### 3.3 关键设计点

| 设计 | 说明 |
|------|------|
| **Service 不继承 BaseService** | 自己在 `__init__` 里 `HttpClient(...)` 构造，框架不持有凭据 |
| **端点传完整 URL** | `HttpClient.url()` 自动判断：完整 URL 直通，端点路径拼 `base_url` |
| **ServiceSpec 无 needs_ctx** | 所有 Service 都是无参构造，自己管 HttpClient |
| **probe 是完整 URL** | 门禁探测用 `GET https://www.baidu.com/s`，200 即可用 |

## Step 4：修改用例（1 分钟）

脚手架默认生成的是 ping 用例。改成搜索用例：

### 4.1 打开 `baidu/test_baidu.py`

### 4.2 改写为：

```python
from apisk.support.markers import feature, story, title

pytestmark = [feature("百度搜索"), story("冒烟")]


@title("SMOKE-01 搜索天气返回 200")
def test_search_status(metric_svc, report_data):
    resp = metric_svc.baidu.search("天气")
    report_data("status_code", resp.status_code)
    report_data("elapsed_ms", round(resp.exchange.elapsed_ms, 1))
    assert resp.status_code == 200, resp.exchange.summary()


@title("SMOKE-02 搜索响应时间 < 5s")
def test_search_elapsed(metric_svc, report_data):
    resp = metric_svc.baidu.search("天气")
    elapsed_ms = round(resp.exchange.elapsed_ms, 1)
    report_data("status_code", resp.status_code)
    report_data("elapsed_ms", elapsed_ms)
    assert elapsed_ms < 5000, f"{resp.exchange.summary()} 超过 5000ms"
```

### 4.3 夹具对照

| 夹具 | 作用 |
|------|------|
| `metric_svc` | **Services() 无参构造**，自动装配所有领域的 ServiceSpec。带门禁：服务不可用时自动 skip |
| `report_data` | 往报告表格写指标：`report_data("status_code", 200)` |
| `metric_svc.baidu.search("天气")` | 由领域 `ServiceSpec("baidu", BaiduService)` 决定属性名 |

## 常见问题排查

### Q1：用例全被 skip

```
SKIPPED 原因: 被测服务当前不可用（UNREACHABLE: HTTPSConnectionPool...）
```

**排查步骤**：
1. 直接在浏览器访问 `https://www.baidu.com`，确认网络通畅
2. 检查领域包的 `probe=` 端点地址是否正确
3. 检查 `BaiduService.__init__` 里 `HttpClient(base_url=...)` 是否正确

### Q2：HTTP 200 通过，但断言"响应体未包含关键词"失败

这是**百度反爬**——对无 User-Agent 或频率过高的请求返回"网络不给力，请稍后再试"的安全验证页。

**解决方法**：在领域包的 HttpClient 里加默认请求头：

```python
class BaiduService:
    def __init__(self):
        self.api = BaiduApi(HttpClient(
            base_url=config.BASE_URL,
            timeout=config.TIMEOUT,
            default_headers={"User-Agent": "Mozilla/5.0 ..."},
        ))
```

### Q3：报 `Exit 4 领域加载失败`

框架会打印：

```
Exit: 领域加载失败: 无法导入领域包 'no.such.domain'

领域声明来源（可并用，本次已尝试）：
  --apisk-domain MODULE   命令行
  apisk_domains = MODULE  pytest.ini
  AUTO_TEST_DOMAINS      环境变量
  本次声明: no.such.domain

请确认写的是**可导入的模块路径**（点号分隔），例如：
  apisk_domains = domain.baidu_domain
```

**原因**：`pytest.ini` 里的 `apisk_domains` 写错了。应该是模块路径，不是文件路径。

**修复**：打开 `pytest.ini`，确认：

```ini
apisk_domains =
    domain.baidu_domain
```

### Q4：没有生成 HTML 报告

- 少装 pytest-html：`pip install pytest-html`
- 报告路径固定在 `<套件根>/reports/report.html`，由 conftest.py 里 `apisk_report()` 钩子自动钉住

## 架构回顾

跑完之后理解一下框架怎么工作的：

```
pytest 启动
  │
  ├─ entry_point pytest11: apisk = "apisk.pytest_plugin"
  │     │
  │     ├─ 加载领域：domain/baidu_domain.py → DOMAIN = Domain(...)
  │     │    ├─ probe="https://www.baidu.com/s" → 门禁探测（GET 一下）
  │     │    └─ services=[ServiceSpec("baidu", BaiduService)]
  │     │
  │     ├─ metric_svc fixture → Services() → 遍历所有 ServiceSpec
  │     │    └─ spec.build() → BaiduService() → HttpClient(...) 构造完成
  │     │
  │     └─ service_status fixture → _probe_client() → 从第一个 Service.api._http 做 GET
  │
  ├─ conftest.py: apisk_report() 注入 pytest_configure 钩子
  │     └─ 钉住 config.option.htmlpath = reports/report.html
  │
  ├─ 用例执行：test_search_status(metric_svc, report_data)
  │     └─ metric_svc.baidu.search("天气")
  │           └─ self.api.search(keyword)
  │                 └─ HttpClient._get("https://www.baidu.com/s", params={"wd": "天气"})
  │                       └─ requests.get(...) → ApiResponse(status_code=200)
  │
  └─ 报告生成：pytest-html 读 user_properties → 渲染状态码、响应时间列
```

**框架只做三件事**：领域加载 + Service 装配 + 门禁探测。其余全是领域包和用例自己的事。
