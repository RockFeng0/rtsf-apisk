# 接入教程：领域包写法详解

本文档聚焦**领域包怎么写**——apisk 的业务接入核心。脚手架命令、套件三件套、用例编写、
执行报告等实操流程详见 [快速接入：百度搜索示例](快速接入-百度搜索示例.md)。

---

## 1. 谁写在哪

| 层 | 写什么 | 你不该在这里做的事 |
|----|--------|--------------------|
| **领域包** `domain/mydomain_domain.py` | 端点类、服务、探活、业务常量 | 不碰 pytest 夹具之外的框架内部 |
| **套件工程** `test_mydomain/` | 用例 | 不直接拼 URL、不直接 import requests |

脚手架生成 `domain/xxx_domain.py` 时已把四部分放在一个文件里，按顺序阅读即可。

---

## 2. 领域包的四个部分

以 ASR 评分接口为例：

### 2.1 业务常量：`Config`

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class AsrConfig:
    """业务常量（端点、阈值等），由领域自己持有。"""
    ASR_HOST = "https://api.example.com"
    ASR_PATH = "/api/v1/asr/score"
    TIMEOUT = 30
```

**设计约束**：
- 框架零配置、零 env var。所有业务常量（base_url、端点路径、阈值、契约字段）
  都在领域自己的 frozen dataclass 里；
- 领域包想读环境变量可以自己读（如 `os.environ.get("ASR_HOST", ...)`），
  框架不干预、不感知；
- 不要写进 `apisk/core/` 任何位置。

### 2.2 端点映射：`Api`

```python
from apisk.api import BaseApi

class AsrApi(BaseApi):
    """一个方法对应一个端点，只发请求，不做业务判断。"""

    def score(self, audio_url, **kwargs):
        """POST /api/v1/asr/score"""
        return self._post(
            f"{config.ASR_HOST}{config.ASR_PATH}",
            json_body={"audio_url": audio_url},
            **kwargs,
        )
```

**设计约束**：
- 端点方法传**完整 URL**。`HttpClient.url()` 会自动判断——以 `http(s)://` 开头就直通，
  否则拼 `base_url`；
- HTTP 动词辅助统一带下划线：`_get` / `_post` / `_put` / `_patch` / `_delete`
  （避免与端点方法名冲突）；
- 三个参数通道：查询串 `params=`（GET/DELETE）、请求体 `json_body=`、
  表单/文件 `data=` / `files=`；
- 这里**不做**字段映射、不做业务判断，只管发。

### 2.3 业务服务：`Service`

```python
class AsrService:
    """业务服务层：自有 HttpClient，无参构造。"""

    def __init__(self):
        self.api = AsrApi(HttpClient(
            base_url=config.ASR_HOST,
            timeout=config.TIMEOUT,
        ))

    def score(self, audio_url):
        """把 ApiResponse 翻译成用例关心的业务对象。"""
        resp = self.api.score(audio_url)
        return AsrResult(
            status_code=resp.status_code,
            score=resp.json.get("score"),
            elapsed_ms=resp.exchange.elapsed_ms,
        )
```

**设计约束**：
- **不继承 BaseService**（框架里已删除这个类）；
- **自己在 `__init__` 里 new HttpClient**。框架不持有凭据、不注入身份、不切换；
- 需要鉴权？就在这里的 HttpClient 里传 `token=...`、自定义请求头等；
- 框架的 `Services` 容器调 `ServiceSpec.build()`（即 `factory()`）——**无参构造**，
  把实例挂到容器上（`metric_svc.asr.score()`）。

### 2.4 门禁探测：`probe`

两种写法，任挑一种：

```python
# 写法 A：直接写 URL 字符串（最简单）
DOMAIN = Domain(..., probe=f"{config.ASR_HOST}{config.ASR_PATH}")

# 写法 B：callable，返回 (bool, str)
def probe_asr(client) -> Tuple[bool, str]:
    try:
        resp = client.get(f"{config.ASR_HOST}/health", timeout=10)
    except requests.RequestException as exc:
        return False, f"UNREACHABLE: {exc}"
    return True, f"OK (HTTP {resp.status_code})"

DOMAIN = Domain(..., probe=probe_asr)
```

**设计约束**：
- `require_service` 夹具据此 **skip 而非 fail**——环境问题不算用例失败；
- 完全不声明时框架退化为「拿第一个 Service 的 HttpClient 做 GET」；
- 多个领域包的 probe 由**第一个声明了该项的领域**生效。

## 3. 领域声明：`DOMAIN`

```python
DOMAIN = Domain(
    name="asr",
    apis={"score": AsrApi},
    services=[ServiceSpec("asr", AsrService)],
    probe=f"{config.ASR_HOST}{config.ASR_PATH}",
    config=config,
)
```

| 字段 | 说明 |
|------|------|
| `name` | 必填，去重用 |
| `apis` | 可选，端点类登记表（端点级用例可按名取用） |
| `services` | 可选，决定 `metric_svc.<name>` 上有哪些属性 |
| `probe` | 可选，门禁探测 |
| `config` | 可选，供套件通过 `apisk_domain_config` 夹具读取 |
| `plugin` | 可选，领域自带的 pytest 插件模块路径（`"mydomain.pytest_plugin"`） |

两条要点：

- `ServiceSpec("asr", AsrService)` 的第一个参数就是**用例里的属性名**：
  `metric_svc.asr.score()`；
- 每个领域包可以有**任意多个 ServiceSpec**——订单、用户、报表各自是独立的
  Service，各自持有自己的 HttpClient。

完整字段表见 [参考：Domain 字段](../reference/domain.md)。

## 4. 领域的加载来源

| 优先级 | 来源 | 示例 |
|--------|------|------|
| 1 | 命令行 | `--apisk-domain domain.asr_domain` |
| 2 | `pytest.ini` | `apisk_domains = domain.asr_domain` |
| 3 | 环境变量 | `AUTO_TEST_DOMAINS=domain.asr_domain,domain.anti_domain` |
| 4 | 入口点 | pip 安装的领域包通过 `[project.entry-points."apisk.domains"]` 自动发现 |

多个领域可以**同时加载**：`Domain.name` 重复会报错（不做静默覆盖）；`probe` / `config`
由**第一个声明了该项的领域**生效。

加载失败时框架打印可操作的提示（退出码 4），不会抛 INTERNALERROR。

## 5. 常见模式

### 5.1 一个业务、多个端点

在 Api 类里加方法，在 Service 类里加对应的业务方法：

```python
class OrderApi(BaseApi):
    def get_order(self, order_id, **kwargs): ...
    def list_orders(self, user_id, **kwargs): ...

class OrderService:
    def detail(self, order_id):
        resp = self.api.get_order(order_id)
        return OrderResult(resp.json, resp.exchange.elapsed_ms)

    def list_by_user(self, user_id):
        resp = self.api.list_orders(user_id)
        return OrderList(resp.json, resp.exchange.elapsed_ms)
```

### 5.2 多个业务、各自独立

每个业务一个 ServiceSpec，各自在 `__init__` 里构造自己的 HttpClient：

```python
DOMAIN = Domain(
    name="shop",
    apis={...},
    services=[
        ServiceSpec("order", OrderService),
        ServiceSpec("user", UserService),
        ServiceSpec("report", ReportService),
    ],
    ...
)
# 用例：metric_svc.order.xxx() / metric_svc.user.xxx() / metric_svc.report.xxx()
```

### 5.3 需要鉴权

```python
class SomeService:
    def __init__(self):
        self.api = SomeApi(HttpClient(
            base_url="https://api.example.com",
            token="jwt-token-here",        # 或从 config 读
            timeout=30,
        ))
```

框架不持有凭据、不注入、不切换——每个 Service 自己管。

### 5.4 领域自带夹具（进阶）

领域需要专属夹具（评估器、第三方客户端等）时，新建一个 `domain/mydomain_plugin.py`：

```python
# domain/mydomain_plugin.py
import pytest

@pytest.fixture(scope="session")
def mydomain_evaluator():
    return MyEvaluator()
```

然后在领域声明里加上 `plugin=`：

```python
DOMAIN = Domain(
    ...,
    plugin="domain.mydomain_plugin",   # 框架加载领域时自动注册
)
```

## 6. 套件两件套怎么来的

脚手架自动生成，一般不需要改。但要理解它们的作用：

| 文件 | 作用 | 什么时候需要改 |
|------|------|----------------|
| `conftest.py` | `apisk_report` 标题/指标列 | 换了指标就要改 |
| `pytest.ini` | `apisk_domains` 声明接入哪些领域 | 加新领域就要改 |

apisk 框架通过 pip install 的 entry_point 自动注册，套件不需要写 `pytest_plugins`。

## 7. 常见问题速查

**Q：脚手架生成后跑不起来？**
先看 [快速接入示例 Step 5~6](快速接入-百度搜索示例.md) 的执行验证和排查章节。

**Q：领域加载失败（Exit 4）？**
框架会打印全部声明来源 + 本次声明 + 修正建议。90% 是 `pytest.ini` 里的模块路径写错了——
要写**点号分隔的可导入路径**，例如 `domain.asr_domain`，不是 `domain/asr_domain.py`。

**Q：领域重名？**
两个领域包的 `Domain.name` 都是 `"asr"`。改其中一个的 name 即可。

**Q：ServiceSpec.build() 报 TypeError？**
确认 Service 类是无参构造 `def __init__(self):`。框架调的是 `factory()`，不是 `factory(ctx)`。

**Q：能不能不手写领域包，让 AI 直接生成？**
可以。按 [skills 快速开始](skills快速开始.md) 装两个技能，先用 `apisk-index-sync` 生成接口索引，
再用 `apisk-script-generator` 一句话出领域包 + 用例；手写这篇讲的约定就是生成代码遵循的模板。
